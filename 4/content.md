#### 과적합과 과소적합 (Over- and Under-fitting)

- 과소적합 (Underfitting) : 모델이 훈련데이터조차 제대로 학습하지 못한 상태
    원인 : 모델이 너무 단순하거나 학습횟수(epoch)가 너무 적음

- 과적합 (Overfitting) : 훈련 데이터에는 완벽하지만 새로운 데이터에는 엉망인 상태, 훈련 데이터의 노이즈까지 외워버린 상태
    원인 : 모델이 너무 복잡하거나 데이터가 너무 적거나, 학습을 너무 오래함.

#### 순전파(forward process) & 역전파(backward process)

- 순전파 : 입력 데이터는 네트워크의 입력층으로 전달되어 첫번째 은닉층으로 보내진다.
        -> 해당 층에 있는 모든 뉴런의 출력을 계산(가중합 + bias -> 활성화함수)하고 결과를 다음층에 전달
        -> 이 단계를 마지막 출력층의 출력을 계산할 때까지 반복한다.

- 역전파 : 출력층에서의 예측결과와 실제 정답 값사이의 오차를 손실함수를 기준을 계산된다.
        -> 계산된 오차에 각 출력연결이 기여하는 정도를 편미분으로 미분값을 계산하고 chain rule을 적용하여 이전 층의 가중치가 오차에 기여하는 정도를 계산하여 
        -> 경사하강법을 사용하여 오차 그레이디언트를 이용해 네트워크의 가중치를 업데이트한다.

#### 경사하강법

- 경사하강법 : 비용 함수를 최소화 하기 위해 반복해서 파라미터를 조정
    ```
    w = w - learning_rate*(∂L/∂w)
    ```

#### 경사하강법 최적화 전략

- 배치 경사 하강법 (BGD, Batch Gradient Descent) , 확률적 경사하강법(SGD, Stochastic Gradient Descent), 미니-배치 경사 하강법 (Mini-batch Gradient Descent)

- 배치 경사 하강법 : 전체 데이터셋에 대한 오류를 구한 후 기울기를 한 번만 계산하여 모델의 파라미터를 업데이트, 한 스텝에 모든 훈련 데이터셋을 사용하므로 학습이 오래 걸린다.

- 확률적 경사하강법 : 전체 데이터셋 대신 매번 하나의 훈련 샘플을 무작위로 선택해서 그레디언트 계산

- 미니-배치 경사하강법 : 전체 데이터셋을 미니 배치 여러개로 나누고, 미니 배치 한 개마다 기울기를 구한 후 그것의 평균 기울기를 이용하여 모델을 업데이트, SGD보다 안정적이고 BGD 보다 빠른 수렴

#### 학습률 (Learning rate)

- 학습률이 크면 많이 이동하고, 학습률이 작으면 적게 이동, tradeoff

#### 옵티마이저(optimizer)

- 경사하강법의 파라미터 변경 폭이 불안정한 문제를 해결하기 위해 학습 속도와 운동량을 조절하는 옵티마이저를 적용한다.
    ex.
    ```
    SGD
    Momentum
    NAG
    Adagrad
    Adadelta
    Rmsprop
    ...
    ```

ex. Adam : 그래디언트의 제곱근 평균과 모멘텀의 추정치를 기반으로 가중치의 업데이트에 사용되는 학습률을 자동으로 조정해준다.

#### 오차 계산하기

- 손실 함수를 사용해서 정답과 예측간의 오차 계산하고, 오차에 영향을 주는 가중치를 업데이트

- 미세 조정 (Fine tuning) : 딥뉴럴네트워크의 파라미터(가중치)의 값을 변경하는 과정

- 대표적인 손실함수
    선형 회귀의 경우, '평균 제곱 오차 손실(MSE Loss)'
    ```
    MSE = (1/N) * sigma[1,n](y_i - expected_y_i)^2
    ```

    로지스틱 회귀의 경우, '교차 엔트로피 손실(Cross-entropy Loss)'
    ```
    CE_Loss = -(1/N) * sigma[1,N]sigma[1,M] y_ij*log(expected_y_ij)
    ```
    즉, 출력 레이어에서 softmax 함수를 활성화 함수로 사용하여, 예측한 확률 분포와 실제 분포 사이의 차이를 최소화 하려는 목적을 가진 손실함수이다.
