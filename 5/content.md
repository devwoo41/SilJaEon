#### 딥러닝 모델의 구현 과정

- 데이터 준비, 모델 정의(모델 컴파일), 모델 훈련, 모델 예측

- 데이터 준비 : 공공 데이터셋 저장소나 유명한 공개 데이터 저장소, 메타 포털에서 다운롣,

- 모델 정의 및 컴파일 : 모델 알고리즘 선택 (ex. MLP, RNN, BERT, GPT ...)
                    모델 컴파일 시, 활성화 함수, 손실 함수, 옵티마이저를 선택, 데이터 형태에 따라 다양한 옵션을 선택 가능하다. 회귀 문제의 경우, loss로 MSE loss를 사용하거나, 분류 문제의 경우, crossentropy loss를 사용 가능하다.

- 모델 훈련 : 한 번에 처리할 데이터양을 지정하고 입력한다. 한번에 처리해야 할 데이터양을 많게 설정한다면 학습 속도가 느려지고 메모리 부족 문제를 야기할 수 있다. epoch, batch, step등을 설정해야 한다.
    ex. 데이터 샘플 수가 100이고, batch number가 16인 경우, 학습 step의 수는 7이 된다.

- 모델 예측 : 검증 (또는 테스트) 데이터셋을 생성한 모델에 적용하여 실제 결과값을 예측을 하는 단계
    예측의 정확도가 낮다면 파라미터를 튜닝하거나 신경망 자체를 재설계해야 한다.

- 딥러닝 학습을 위한 데이터 종류
    ```
    전체 데이터
    |----------|
    훈련 데이터 : 학습에 사용되는 데이터
    |------|
    검증 데이터 : 학습에는 사용하지 않지만, 모델 훈련에 기여하는 데이터
    |--|
    테스트 데이터 : 학습에 사용되지도, 기여하지도 않고 모델의 검증을 위해 사용하는 데이터
    |--|
    뭐 대충 이런식으로 분할 한다.
    ```

- 과적합 문제 : 학습 데이터에 대해서는 오차가 감소하지만, 검증 데이터에 대해서는 오히려 오차가 증가하는 현상, 훈련 데이터를 과하게 학습하는 경우 이런 문제가 발생한다.

```
하이퍼 파라미터 예시
optimizer : 어떤 최적화 알고리즘
activation function : 어떤 활성화 함수
hidden size : 각 은닉층에 몇개의 은닉 뉴런을 사용할지
number of hidden layer : 은닉층을 몇층으로 할 것인지
learning rate : 학습률을 얼마로 할 것인지
epoch number : 전체 데이터를 몇 번이나 학습할지
batch number : 한 번 가중치를 업데이트 할때 몇 개의 샘플을 볼 것인지
loss function : 어떤 손실 함수를 사용할 것인지
```
