#### 미분

- *순간 변화율 (=미분계수)* : 어느 한 점에서의 접선의 기울기

    미분계수가 0인 지점에서 *극댓값* 또는 *극솟값*을 갖는다.

- 미분가능성 : x=a에서 연속이고 좌미분계수와 우미분계수가 동일할때, 미분이 가능하다.

- 미분의 기본공식
    ```
    x^n = n * x^(n-1)
    ```

#### 편미분

- *편미분*이란 변수가 여러개인 다변수 함수의 특정 변수를 제외한 나머지 변수를 상수로 간주하여 미분하는 것, 여러가지 변수가 식 안에 있을 때, 우리가 원하는 한가지 변수만 미분하고 그 외에는 모두 상수로 취급한다.

- 편미분이 중요한 이유는 딥러닝의 학습과정을 이해하는데 중요하기 때문이고, 딥러닝의 목적은 오류(손실, loss)를 최소화하는 가중치(w)와 바이어스(b)를 찾는 것이다.

#### 머신러닝과 딥러닝의 차이

- 딥러닝은 대량의 데이터를 신경망에 적용하면 컴퓨터가 스스로 분석한 후 답을 찾는다. 즉, 데이터의 특징을 추출하는 작업을 인간이 진행하던 머신러닝의 그 과정이 필요가 없는 것이다.

#### 딥러닝 알고리즘의 종류

ex. ```
    지도 학습 - 이미지 분류 : CNN, ResNet, ...
            |- 시계열 데이터 분석 : RNN, LSTM

    비지도 학습 - 군집 : 가우시안 혼합 모델, 자기 조직화 지도 ...
              |- 차원 축소 : AutoEncoder, 주성분 분석

    전이 학습 - BERT, MobileNetV2

    강화 학습 - 마르코프 결정 과정
    ```

#### 뉴럴 네트워크

- 딥러닝의 핵심, 두뇌의 신경세포 뉴런이 연결된 형태를 모방한 모델

#### 퍼셉트론

- 가장 간단한 인공신경망 구조로, *입력*과 *출력*이 숫자이고, 각각의 입력 연결은 *가중치*와 연관되어 있다. 입력의 가중치 합을 계산한 다음 계산된 합에 *계단 함수(step function)* 을 적용하여 결과 출력

- 입력 뉴런 2, 편향 뉴런 1, 출력 뉴런 3으로 구성된 퍼셉트론 (입력층의 노드 3개, 출력층의 노드 3개의 형태이다.)

- 입력 뉴런 : 퍼셉트론의 입력으로 어떤 입력이 주입되든 출력 방향으로 통과시킴, 입력층 : 입력 뉴런의 집합 (층)

- 편향 뉴런 : 편향 특성을 더해주기 위해 사용 됨, 편향은 퍼셉트론의 활성화 정도를 조절할 수 있음.

- 출력 뉴런 : 출력을 결정하는 뉴런

- 퍼셉트론의 학습 방법은 뉴런이 다른 뉴런을 활성화 시킬 때, 이 *두 뉴런의 연결(가중치)*가 더 강화되도록 학습되어야 한다. 네트워크가 예측할 때 만드는 오차를 반영하도록 훈련이 된다. 

- 잘못된 예측을 하는 모든 출력 뉴런에 대해 올바른 예측을 만들도록 연결을 강화.
```
w_ij_(nextstep) = w_ij + learning rate * (y_j - expected y__j) * x_i
```

#### 퍼셉트론의 한계

- XOR 연산 문제를 해결하지 못한다. 이에 따라 평면을 휘어주면 XOR 문제를 극복할 수 있다.

#### 다층 퍼셉트론 (MLP, Multi-Layer Perceptron)

- 입력층 : 데이터를 받아들이는 첫번째 층

- 은닉층 : 신경망의 복잡성과 처리 능력을 담당하는 층, 한개 이상의 은닉층을 가져야 "다층"이라고 부른다.

- 은닉층을 여러 개 쌓아 올린 신경망이다. 입력층에서 출력층으로 신호가 한 방향으로만 전달되는 구조이다.
    ```
    피드포워드(feedforward neural network)
    역전파를 통해 학습
    ```

#### 심층신경망 (DNN, Deep Neural Network)

- DNN은 딥러닝을 구현하기 위한 이론과 알고리즘의 집합을 가리킨다. 
    ```
    층 : 입력층, 은닉층, 출력층
    가중치 : 노드와 노드 간 연결 강도
    바이어스 : 가중합에 더해주는 상수로, 활성화 함수를 거쳐 최종적으로 출려되는 값을 조절
    가중합 전달 함수: 가중치와 신호의 곱을 합한 것
    활성화 함수 : 신호를 입력받아 이를 적절히 처리하여 출력해주는 함수
    손실 함수: 가중치 학습을 위해 출력함수의 결과와 실제 값 간의 오차를 측정하는 함수
    ...
    ```

- 은닉층의 역할은, 활성화 함수가 적용된 여러 은닉층을 결합하여 비선형 영역을 표현하는 것이다. 따라서 은닉층이 많아질수록 데이터를 더 정확하게 분류할 수 있다.

- 시그모이드 함수 : S자형 곡선 또는 시그모이드 곡선을 갖는 함수 
    but 딥러닝 모델의 깊이가 깊어지면 기울기가 사라지는 '기울기 소멸 문제(vanishing gradient problem)'이 발생하여 최근 딥러닝 모델에서는 잘 사용하지 않는다.
    ```
    S(x) = 1 / (1 + e^(-x))
    ```

- ReLU 함수 : 입력이 음수일때는 0을 출력하고, 양수일 때는 x를 출력
    최근 많이 사용되는 활성화 함수로, 기울기 소멸 문제가 발생하지 않는다. 양수에서는 항상 1의 기울기를 가지므로, 문제는 음수 값을 입력받으면 항상 0을 출력해서 학습능력이 감소하고, 이에 따라 *Leaky ReLU*를 사용하기도 한다.
    ```
    ReLU(x) = max(0, x)
    ```

- 소프트맥스 (softmax) 함수 : 출력층의 각 뉴런에 대한 입력값을 0과 1 사이로 변환하고, 이들 값의 합이 1이 되도록 정규화하는 함수
    *다중 클래스 분류* 문제에 자주 사용되는 활성화 함수로, 각 클래스에 대한 예측확률을 계산하는데 사용된다.
    ```
    Softmax(x) = e^x / sum(e^x)
    ````
