#### 자연어처리 

- 언어와 관련된 실용적인 문제를 컴퓨터로 해결하는 방법을 연구하고 개발하는 것

#### 전산언어학

- 인간 언어의 속성을 이해하기 위해 계산 방법을 사용하는 것

#### The Hierarchy of Linguistic Units

=> Sentence(문장) -> Phrase(구) -> Word(단어) -> Morpheme(형태소) -> Phoneme(음소)
    morpheme은 의미를 가진 최소 단위

=> 자연어처리에서의 단어 단위, it depends on tasks or applications

=> NLP에서 words는 텍스트에서 분석 단위로 활용되는 기본 단위이다. 텍스트 전처리, 벡터화, 머신러닝 모델 등의 입력단위를 지칭하고, 목적에 따라 다르게 정의됨.

#### 말뭉치 (Corpus)

- A computer-readable collection of text or speech

- 원시 텍스트 (raw text)와 메타 데이터 (meta-data)
    원시 텍스트 : 문자(바이트)의 시퀀스
    메타 데이터 : 텍스트와 관련된 식별자, 레이블 및 타임 스탬프와 같은 보조 정보

#### 전처리 (Pre-processing)

- 자연어처리의 가장 첫 단계로, 풀고자 하는 문제를 위해 텍스트를 정제
```
토큰화
단어 정규화
불용어 처리
벡터화
```

#### 토큰화 

- 문자를 연속적인 단위인 토큰으로 분해하는 것
    영어에서는 일반적으로 공백 문자 또는 구두점으로 구분된 단어 및 숫자 시퀀스를 토큰으로 간주
    한국어에서는 일반적으로 형태소 단위로 토큰화

- 최근에는 서브워드(subword)라고 불리는 토큰 단위를 주로 사용한다.

#### 단어 정규화 (word normalization)

- case folding : 모든 단어를 대문자 또는 소문자로 일치
    
- Lemmatization : 단어의 뿌리를 의미하는 기본 사전형 단어(어근)으로 변환

- Stemming : 어형 변화의 기초가 되는 부분이자 단어의 의미를 담고 있는 단어의 핵심 부분

#### 불용어 처리

- 분석에 큰 의미가 없는 단어를 제거, 자연어처리 과제 종류에 따라 불용어는 달라질 수 있다.

#### 벡터화 (Vectorization)

- 단어, 문장, 문서를 컴퓨터가 이해할 수 있도록 숫자화해주는 과정

1. 등장 횟수 기반의 단어 표현 : 희소 표현(Sparse representation)이라고도 함. ex. one-hot encoding, BoW, TF-IDF

2. 분포 기반의 단어 표현 : 밀집 표현(Dense representation)이라고도 함. ex. Word2Vec, GloVe, ELMO, BERT

#### 전통적인 자연어 처리의 단계

- 자연언어 문장 -> *형태소 분석* -> *구문 분석* -> *의미 분석* -> *화용 분석*

- 형태소 분석 : 문장을 의미를 가진 가장 작은 단위인 *형태소*로 분리
    ```
    ex. 나는 사과를 먹었다
        나는 = 나/명사 + 는/조사
        사과를 = 사과/명사 + 를/조사
        먹었다 = 먹/명사 + 었다/과거형 어미 
    ```

- 구문 분석 : 문장을 구성하는 성분들간의 관계를 분석

    *의존 구문 분석* : 문장 구성 성분간의 의존 관계를 분석

- 의미 분석 : 문장이 나타내는 의미를 분석하여 표현

    *단어 중의성 해소* : 단어가 현재 문장에서 어떤 의미인지 분석

    *의미역 결정* : 서술어와 관계있는 논항의 역할을 결정

- 화용 분석 : 문장을 해석해서 화자의 의도를 파악하는 단계

    *상호참조해결*
        ex. 그는 어제 사과를 책상위에 두었다. 그것은 아주 빨간 색이었다. -> 그것 : 사과
    
    *화행 분석* 
        ex. 방이 좀 추운것 같지 않아? -> 온도 향상 요청

#### 머신러닝

- 컴퓨터가 대용량 데이터에서 지식이나 패턴을 찾아 학습하고 예측을 수행하는 것, 컴퓨터가 학습할 수 있게 하는 알고리즘과 기술을 개발하는 분야

#### 머신러닝의 단계

- 학습 : 데이터를 사용하여 모델이 특정 목적을 달성하도록 하는 과정

- 예측 : 학습으로 생성된 모델에 새로운 데이터를 적용하여 결과를 예측, 머신러닝의 목표는 예측을 잘하는 것

#### 머신러닝의 학습 과정

- 학습 데이터 준비
    => 실제 데이터의 특징이 잘 반영되고 편향되지 않는 훈련 데이터를 확보해야 함

- 특성 추출 
    => 데이터가 컴퓨터를 인지 할 수 있게 변환 필요

- 머신러닝 알고리즘 적용 & 모델 생성
    => 학습 단계에서 얻은 최종 결과물 (가설함수)

- 이 세 단계를 반복하면서 주어진 문제를 가장 잘 풀 수 있는 모델을 찾음

#### 머신러닝의 예측 과정

- 테스트 데이터 준비
    => 학습 데이터와 다른 새로운 데이터

- 특성 추출
    => 학습과 같은 방법으로 특성을 추출

- 예측 및 결과 도출
    => 학습된 모델에 새로운 데이터를 입력하여 예측 수행

#### 자연어처리의 발전

- *전통적 기법 (Rule-based approach) -> 머신러닝 기법 (Machine-learning based approach)*

- 전통적 기법 : 사람이 직접 정의한 규칙대로 응답하도록 명시적으로 프로그래밍

- 머신러닝 기법 : 자주 나타나는 패턴을 갑지하여 어떤 단어와 구절이 문제를 해결하는데 좋은 기준인지 자동으로 학습

#### 머신러닝 알고리즘의 종류

- *지도학습(Supervised Learning)*, *비지도학습(Unsupervised Learning)*, *강화학습(Reinforcement Learning)*

- 지도학습 : 학습데이터에 레이블(label) 이라는 원하는 답이 포함된 학습 방법, 정답이 레이블링된 데이터가 필요하다.

    지도학습의 목표는 학습된 정보를 기반으로 새로운 데이터를 올바르게 예측하는 것

    회귀 (Regression) : 연속적인 숫자(실수)를 예측하는 것
    분류 (Classification) : 미리 정의된, 가능성이 있는 여러 클래스 중 하나를 예측하는 것

- 주요 지도학습 알고리즘들
    ex.
    ```
    K-최근접 이웃
    선형 회귀
    로지스틱 회귀
    서포트 벡터 머신
    결정 트리
    신경망
    ```

- 비지도학습 : 레이블이 없는 학습 데이터에서 의미를 찾아내는 방법

    비지도 학습의 목표는 주어진 데이터에서 패턴이나 구조를 발견하도록 학습

    데이터 군집화 (clustering) :  유사한 패턴을 갖는 데이터를 그룹화하는 것
                                비슷한 데이터 샘플을 군체(cluster)로 모으는 작업
    데이터 차원 축소 및 시각화 : 고차원의 벡터를 저차원으로 변환하여 분석하는 것
    이상치 탐지 : 정상 데이터에서 벗어난 특이 패턴 감지

- 주요 비지도학습 알고리즘들
    ex.
    ```
    군집 : k-평균, DBSCAN, 계층 군집 분석
    시각화와 차원 축소 : 주성분 분석 (PCA) ,커널, locally linear embedding, T-SNE
    이상치 탐지와 특이치 탐지 : One-class SVM, Isolation Forest
    ```

- 강화 학습 : 반복적인 시행착오와 상호작용을 통해 수행방법을 학습, 학습하는 시스템인 에이전트가 환경을 관찰해서 행동을 실행하고 그 결과로 보상 또는 벌점을 받음 / 마르코프 결정 과정 (MDP)

    강화학습의 목표는 보상을 최대화 할 수 있는 전략을 학습하는 것이다. 이에 따라 *Reward Hacking*이라는 목표 기능을 최적화 하여 목표의 문자 그대로를 형식으로서 받아들일때 발생하는 문제이다.

- 자연어처리를 위한 강화학습 알고리즘
    ex. RLHF (Reinforcement Learning from Human Feedback) : 인간의 피드백을 기반으로 언어모델이 최적의 답변을 하도록 강화학습을 하는 머신러닝 기법
    ```
    prompt dataset (질문 묶음)
    |
    Initial Language model : 답 생성
    |
    Generated text -> Human scoring -> Preference 수집
    |
    Preference - reward model(사람 판단을 학습한 별도 모델)
    |
    reinforcement learning : 이 보상 모델을 기준으로 LM을 업데이트
    ```
